# 08 测试与证据

## 1. 证据原则

生产就绪不是“测试跑过一次”，而是：

- 当前提交有对应证据。
- 关键能力有正常、异常、并发、回滚测试。
- 真实环境有部署和运维证据。
- 失败项和未覆盖项被明确记录。
- 证据可复核、可追溯、可重复。

## 2. 测试分层

| 层级 | 目标 | 例子 |
|---|---|---|
| 静态检查 | 规则、依赖、权限、Secret | 安全扫描、@PreAuthorize、裸抛异常、错误码 |
| 单元测试 | 领域规则和边界 | BigDecimal、状态机、AQL、幂等键 |
| 组件测试 | 单模块 + DB/Redis | Mapper、事务、租户过滤 |
| 集成测试 | 跨模块链路 | ERP->WMS、QMS->WMS、MES->WMS |
| 契约测试 | API/事件兼容 | 事件版本、DTO、状态枚举 |
| 迁移测试 | Flyway 和验证脚本 | 沙箱 shadow-run、幂等重跑 |
| 性能测试 | 延迟、吞吐、资源 | 并发下单、报工、库存、查询 |
| 故障测试 | 依赖失败和恢复 | Redis/DB/MQ 中断、DLQ、重放 |
| 安全测试 | 认证、授权、注入、租户 | 越权、跨租户、Secret、TLS |
| 运营测试 | 部署、备份、灾备、告警 | K8s、PITR、RTO/RPO、on-call |
| 合规测试 | 审计、签名、保留、隐私 | 电子签名、数据导出、删除权 |
