## 2. 对标结论

### Odoo / ERPNext

值得学习：

- 库存、采购、销售、制造、财务的统一单据链。
- 主数据和会计科目的强关联。
- 模块化但共享业务语义。
- 单据状态和业务规则集中管理。

不要照搬：

- 许可证和模块授权不同。
- 数据模型和 UI 生态差异大。
- 直接复制代码可能带来许可和升级风险。

### Carbon / qcadoo MES / industry4.0-mes

值得学习：

- 工单、工序、报工、设备、质量的一体化。
- 生产现场数据采集和实时看板。
- 质量异常和生产流程的联动。

### GreaterWMS / ModernWMS / OpenWMS

值得学习：

- 收货、上架、拣货、复核、发运、盘点流程。
- 库存预占、批次、序列号、库位。
- PDA 和作业任务模型。

### ruoyi-vue-pro / yudao-cloud

值得学习：

- 权限、租户、工作流、代码生成、基础设施。
- 单体版和微服务版的分层与边界。
- 本项目的上游兼容和升级路径。

### Aureuserp / Akaunting

值得学习：

- 现代 ERP 技术栈和财务模块。
- 会计、税务、报表和用户权限。

## 3. 与本项目的关系

本项目已经吸收了 ruoyi-vue-pro 的基础能力，并扩展了 ERP/MES/WMS/QMS/CRM/HR/OA/TMS 和 AI。当前应重点补齐：

1. 跨域一致性：库存、质量、工单、回款。
2. 模块边界：`api` 包、事件契约、禁止跨模块 DAL。
3. 生产工程：TLS、K8s、备份、灾备、SLO。
4. 合规：等保、个保法、行业标准。
5. 测试：核心域并发、异常、幂等、回滚。

## 4. 后续建议调研

- QMS：SPC、CAPA、8D、IATF 16949、GMP、21 CFR Part 11。
- TMS：VRP、运输结算、GPS 隐私、电子回单。
- HR：薪酬合规、个保法、考勤规则。
- OA：公文、电子签章、知识库权限。
- SRM：供应商准入、询报价、采购协同。
- EAM：设备维修、备件、可靠性。
- PLM：BOM、ECN、工艺、图纸。
- BI：指标平台、数据仓库、语义层。
- 安全：OWASP ASVS、SLSA、SBOM、密钥管理。
- 合规：等保 2.0、ISO 27001、SOC 2、GDPR。
