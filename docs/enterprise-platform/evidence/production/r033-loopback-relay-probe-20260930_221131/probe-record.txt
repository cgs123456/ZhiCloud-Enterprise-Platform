## 失败与自纠（如实）
第一次中继实现用 nc -e "nc 127.0.0.1 3306"，busybox nc 的 -e 不做词分割，报 nc: can't execute 'nc 127.0.0.1 3306': No such file or directory；此时宿主 TCP 连上 53400 但读到 0 字节（Communications link failure）。改为 wrapper 脚本后成功。

## 边界
- 本实验只证明"来源地址呈现"这一件事，未测迁移全链（数百条语句/DDL/并发连接），busybox nc 中继为单连接 fork，性能与稳定性未量。
- 中继使 @127.0.0.1 授权的"仅回环可达"语义改变：实际可达性由 Docker 在宿主侧只绑 127.0.0.1 的发布方式保证，守卫的含义随之从"账号来源限制"移为"端口发布范围限制"，属安全口径变化，需责任人裁决。
- 未复现生产拓扑（生产是跨网络连远端库），本记录不构成生产等价证据。
- 账号口令为随机生成，容器与卷随后销毁，不在仓库内。
