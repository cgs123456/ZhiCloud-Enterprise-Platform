# @PermitAll 写接口白名单
#
# 格式：<相对路径>#<方法名>，每行一条；# 开头为注释。
# 语义：该写接口确实需要匿名访问，已人工评估并接受风险。
#
# 登记门槛（新增条目必须满足其一，并在上方写明理由）：
#   1. 认证入口本身（登录/注册/刷新令牌/找回密码/验证码）——尚未持有令牌，无法鉴权；
#   2. 第三方回调（支付/短信/OAuth/Webhook）——调用方是外部系统，靠签名或密钥验签而非会话；
#   3. 无副作用的计数类接口——不涉及业务数据，被刷最多是计数不准。
#
# 不满足上述条件的一律不得登记，必须改为 @PreAuthorize。
# 历史教训：WmsPda*Controller 与 MesProPdaFeedbackController 都曾以
# 「由 App 端 token 认证」为由挂 @PermitAll，而 @PermitAll 的语义恰恰是跳过令牌校验，
# 注释与实现相反，导致 PDA 写接口长期匿名可达。
